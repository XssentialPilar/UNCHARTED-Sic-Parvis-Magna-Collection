# UNCHARTED: Sic Parvis Magna Collection — v0.6.1 Implementation Plan
## SPM Neural Assist: Optional Native NPU Acceleration & Unified Hardware Optimization

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the v0.6.0 architecture with an optional, hardware-accelerated AI inference subsystem named **SPM Neural Assist** for predictive asset streaming, resource scheduling, and unified hardware optimization (CPU, GPU, RAM, Storage, NPU) targeting **v0.6.1**, maintaining 100% zero-dependency fallback for non-NPU and legacy systems.

**Architecture:** An extensible, vendor-agnostic C++20 abstraction (`ISpmInferenceBackend`, `SpmNeuralAssist`, `SpmNeuralPredictor`, `SpmHardwareCapabilities`) loaded dynamically without static SDK dependencies. It integrates with `SpmAssetStreamer` to predict lookahead horizons, prefetch priorities, and short-term VRAM demand while preserving deterministic game simulation, with complete UI controls and localization across 10 languages.

**Tech Stack:** C++20, CMake, Clang 23 UCRT / MinGW / GCC, Win32 / MCDM / DirectML dynamic loader, ONNX Runtime dynamic loader, SDL3, C# / .NET 10 WPF, CTest.

**Spec:** User request `Extend the proposed v0.6.0 architecture with an optional native NPU acceleration subsystem named SPM Neural Assist`.

---

## Global Constraints
- Target release: `v0.6.1`.
- The NPU must NEVER become a mandatory runtime dependency.
- Dynamic runtime loading only: NO static linking against `directml.lib`, `onnxruntime.lib`, or Windows 11-only SDKs.
- Zero-dependency CPU fallback: systems running Windows 7, 8, 8.1, 10, 11 (without NPU) or Linux must remain 100% functional without errors.
- Never modify gameplay logic, physics, collision, or guest memory via unverified predictions.
- All inference must be asynchronous, non-blocking, and adhere to strict execution budgets (< 1 ms per tick).
- All new UI controls translated into all 10 supported languages (`en`, `es_419`, `es_ES`, `pt_BR`, `fr`, `de`, `it`, `ru`, `ja`, `zh_CN`).
- Real evidence-based benchmarks comparing (1) Conventional CPU prediction, (2) NPU-assisted prediction, and (3) Predictive streaming disabled.

## Review Focus
1. **Dynamic DLL Loading Safety:** System lacks `directml.dll` or `onnxruntime.dll` $\rightarrow$ Graceful fallback to `CpuConventional` with 0 crashes or error dialogs.
2. **NPU Hardware Detection:** Accurately detects AMD Ryzen AI (XDNA), Intel AI Boost, Qualcomm Snapdragon X NPU, or MCDM compute adapters without vendor bias.
3. **Storage Tier Classification:** Accurately classifies NVMe, SATA SSD, and HDD to modulate streaming bandwidth and lookahead distance.
4. **Advisory Invariant Protection:** Predictions adjust only prefetch order, LOD bias, and lookahead distance in `SpmAssetStreamer`; never gameplay state.
5. **Mode Switching & Pacing:** Switching between `Auto`, `Enabled`, and `Disabled` at runtime takes immediate effect without frame drops or memory leaks.
