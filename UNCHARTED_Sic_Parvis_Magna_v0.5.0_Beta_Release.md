# UNCHARTED: Sic Parvis Magna Collection — v0.5.0 Beta

*“Sic Parvis Magna” — Greatness from small beginnings.*

We are pleased to introduce the first public Beta of **UNCHARTED: Sic Parvis Magna Collection**, an independent project focused on bringing a more polished, flexible, and enjoyable PC experience to Nathan Drake's adventures.

## What's New

- **Explorer's Desk Launcher:** A modern interface for managing graphics, display settings, controls, languages, and updates.
- **Keyboard & Mouse Support:** Redesigned vector-based key prompts, with improved proportions and integration throughout the interface.
- **Expanded Display Support:** 4:3, 16:9, 16:10, and 21:9 aspect ratios, with adaptations designed to minimize black bars without stretching the image.
- **Flexible Display Modes:** Fullscreen, Borderless Window, and Windowed.
- **Scalable Graphics:** Adjustable shadow and texture quality for different hardware configurations.
- **Performance Improvements:** Refined frame pacing, memory management, lighting, and rendering efficiency.
- **Automatic Update Checks:** Future releases can be detected through the launcher while preserving user preferences.

## Installation

1. Download and extract the Complete Package.
2. Run `Uncharted - Sic Parvis Magna Collection.exe`.
3. Select your compatible game directory, configure your preferences, and launch the game.

**Important:** Original game files are not included. Windows 10/11 (64-bit) and compatible game files are required.
